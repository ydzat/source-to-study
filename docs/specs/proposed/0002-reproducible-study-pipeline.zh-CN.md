# 可复现的学习管线

Status: proposed

## 问题

手动结合 AI 学习可能产生失效资产路径、无依据引用，以及无法复现导出的复习内容。

## 提案

围绕权利清晰的小课程建立最小管线：来源索引、可编辑教学输入、经过验证的 Notebook 输出、卡片校验与可选 Anki 导出。仓库已附带外部来源 [OnlineStatBook 集中趋势](../../../examples/central-tendency/README.zh-CN.md)，学习者按[跟练教程](../../../guides/first-session.zh-CN.md)生成自己的笔记，不使用预写的参考 Notebook。重建时保留学习者作答。可复用逻辑不绑定课程、机器路径、模型服务商或可选 UI。

[本地工具参考](../../../guides/tools.zh-CN.md)负责已提供的命令与格式。跟练教程及中文 Notebook 流程已经交付并通过[真实会话验收](../implemented/0006-live-tutorial-acceptance.zh-CN.md)。本提案范围更广，仍待独立英文会话和从来源到制卡的整体验收；已有导出测试不代表完整流程已经验证。Anki 采用文件导出，不直接操作应用。

## 考虑过的替代方案

纯文档模板可立即使用，但不能验证可执行产物。优先开发 UI 的方案延后，先让底层流程及失败情况可以测试。不把 ComfyUI 或其他 UI 框架作为必需依赖。

## 验收条件

- 新工作区能按文档中的依赖与命令运行样例。
- 核验来源位置；缺失文件与无依据引用明确报错。
- 生成的 Notebook 在自身目录、干净内核下运行，重建保留学习者作答。
- 卡片标识、问题、答案与来源经过校验；导出包可在导入前检查。
- 测试覆盖缺失资产、非法输入与从真源重建。
- 公开产物不含私人课程摘录、个人路径或凭据。
- 中英说明都能复现相同流程。

## 风险

来源格式不同，文本提取可能遗漏公式。执行通过不能证明概念正确。导出涉及需审查的依赖与格式选择；UI 工作可能掩盖这些尚未确定的约定。
