# Design records

English · [简体中文](README.zh-CN.md)

Use a short numbered topic filename under `proposed/`, `implemented/`, or `rejected/`. Keep the English and Chinese pair together when moving it.

A proposed record contains: Problem, Proposal, Alternatives considered, Acceptance criteria, and Risks. An implemented record contains: Problem, Decision, Alternatives considered, Consequences, and Verification. A rejected proposal retains its reasoning and adds the rejection reason. Do not invent alternatives or verification results.

Update a record when its existing decision changes in detail. A different decision needs a new linked record. Current user instructions remain in their owning files, not only in a historical record.

This lightweight lifecycle adapts the Agent Note approach inspected in deepseek-harness; it does not import that project's plugin architecture, tooling, or documentation automation.
