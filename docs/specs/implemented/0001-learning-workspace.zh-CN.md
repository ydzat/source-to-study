# 以学习工作区为产品

Status: implemented

## 问题

学生需要可复用的学习工作区。以软件开发计划为主的入口无法说明如何开始复习。

## 决定

根 README 指导课程初始化，AGENTS 定义导师行为，双语表单支持本地课程档案、笔记、回忆问题和会话。个人状态保存在被忽略的 `study/`；维护信息位于 `docs/`。[架构文档](../../architecture.zh-CN.md)负责当前布局。

## 考虑过的替代方案

开发计划入口面向贡献者，因此未选为学习入口。填写后的课程状态只维护一份，避免平行翻译产生分歧；表单字段提供双语说明。

## 影响

学习者可结合能读取文件的助手和表单开始，也可使用[工具参考](../../../guides/tools.zh-CN.md)中的本地工具。小样例展示笔记结构，不代表完整课程或已验证的教学效果。

## 验证

实现提供四种表单和双语入口。本地检查通过：22 个 Markdown 文件、58 个相对链接、语言配对和末尾换行。Git 确认 study/COURSE.md 与 materials/example.pdf 被忽略，差异空白检查通过。人工逐项检查初始化说明，未发现虚构的流程命令。这些检查不能验证模型遵循程度或教学效果。
