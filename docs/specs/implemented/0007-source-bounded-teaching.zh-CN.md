# 以课程范围约束教学

简体中文 · [English](0007-source-bounded-teaching.md)

## 问题

模板已经要求从目标讲到结果，但没有逐项检查源材料步骤的覆盖与新增内容的必要性。工具指南要求从正式笔记中暂时省去答案，混淆了完整学习材料与现场测验。执行通过和标题齐全无法证明解释完整。

## 决定

双语[教学指南](../../../guides/teaching.zh-CN.md)负责源内容映射、推理连续性、图与例子的选择、完整笔记答案及四项独立检查。教学 Skill 要求写前读取；笔记、课程和会话表单提供相应填写位置。工具指南已区分现场测验暂不揭晓答案与正式笔记答案完整性。含具体证据的复盘留在父项目，模板只保留通用经验。

## 考虑过的方案

只向 AGENTS 添加规定会重复详细流程；复制优秀课程笔记会连同科目假设和内容深度一起复制；用程序检查标题无法检验缺失的推理。保留现有构建格式，通过源内容映射和人工语义检查补足要求。

## 影响

- 来源步骤对应解释与原因，新增前置和例子有明确用途。
- 正式笔记包含隔离的答案及符合考核的收口；现场测验仍等待作答。
- 分别检查课程覆盖、机制解释、示例一致性和执行结果。
- 分开记录材料就绪、自述完成、跳过内容和独立展示能力。
- 执行入口要求读取指南；双语文档和链接一致。
- 文档测试与改动的 Skill 验证通过；人工检查内容扩展、答案缺失、追问范围、未经测试的课程结束等场景。

## 适用范围与局限

数值计算和口试的固定形式不适合所有科目。指南须支持文本证据和无需代码的推理，允许配置语言与考核形式。私人笔记和固定机器路径不得进入公开模板。本轮不引入依赖或修改构建格式。

观察到的演变是：可复用的单元结构 → 从目标到结果的连续解释 → 完整的持久笔记答案 → 课程范围内的例子与独立语义检查。结构和可执行证据仍有价值；把其中一项视为充分条件，会产生解释缺口或不必要的扩展。这些是迭代使用所得的设计经验，未经学习效果实验测量。

## 验证

2026-09-28，在项目现有环境通过离线 `uv run --no-sync` 运行 `python -m unittest discover -s tests -p test_docs.py -v`，一个遍历公开链接、双语配对与 JSON 示例的测试通过。改动的教学 Skill 通过 `quick_validate.py`；`git diff --check` 未报告空白错误。未安装依赖。

人工对照规则和表单检查了以下场景：

| 场景 | 文档流程检查结果 |
|---|---|
| 源材料给出简短算法，可运行例子可能扩展成完整应用 | 覆盖表要求解释每个步骤的原因；指南允许局部例子，排除无关指标和接口知识。 |
| 学习者尚未回答自测 | 表单要求隔离的完整答案与收口；现场测验仍等待作答。工具指南中的冲突句已移除。 |
| 仅要求回答或要求“正确才继续” | 明确范围和条件优先于既有笔记更新约定；核对未通过时不能推进。 |
| 用户结束复习并跳过一讲，没有独立测试 | 会话表单分别记录自述、跳过和未测；待解决问题保留，不创造新的 Notebook 状态。 |
| 人文类单元没有计算 | 通过证据分析和假设变化完成核验功能，无需加入代码或口试格式。 |
| 新工作区没有范例 | 指南和表单提供初始要求；只有指定且可用的范例才需检查，不依赖私人文件。 |

以上属于人工文档流程检查，未运行独立 Agent 验收或真人学习测试。既有运行代码、私人笔记、生成的示例工作区和历史验收结果均未改写。本轮不宣称完成全新安装、图形界面或端到端教学验收。
