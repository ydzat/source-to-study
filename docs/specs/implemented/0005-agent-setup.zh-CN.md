# Agent 引导的环境部署

简体中文 · [English](0005-agent-setup.md)

## 问题

目前学习者必须先手动安装工具。需要不依赖原生 Skill 发现能力的简短入口。

## 决策

由本地 `sts-setup` Skill 维护唯一部署流程。Windows PowerShell 脚本同步锁定环境并初始化目录；Python 健康检查核验项目解释器、依赖、真实内核和本地 JupyterLab 服务。保留手动安装路径。最后简短报告，要求重启 Agent 并新开会话，提供教程链接。

## 考虑过的替代方案

- 远端安装指南：可能与本地脚本版本不匹配。
- 每次让 Agent 临场生成命令：难以测试和重复运行。
- 静默全局安装：产生不必要的系统改动；复用已有 uv，否则经授权使用官方安装方式。

## 影响

- 中英 README 均提供直接读文件的入口。
- 失败返回非零；重跑保留学习文件。
- 健康检查实际执行代码，启动并停止自己的带认证本地服务。
- 不修改全局 Agent 配置、权限、Anki 或学习状态。
- Windows 新流程及已有测试通过；披露未测试的全新机器引导安装。

## 限制

联网和宿主审批可能阻止安装；全局内核配置可能选择错误解释器。运行日志可能含本地认证令牌，必须保持忽略。PDF 学习流程见[教程](../../../guides/first-session.zh-CN.md)，历史验收见 [0006](0006-live-tutorial-acceptance.zh-CN.md)；环境部署验证不能证明教学行为。

## 验证

Windows、PowerShell 7.6.6、uv 0.12.19 下，20 项 unittest 全部通过，包括 uv 缺失时替换旧成功报告、拒绝错误解释器、真实 JupyterLab 启停和已有课程管线。Skill Creator 的 `quick_validate.py` 通过。没有 `.venv` 的全新项目副本复用已有 uv、Python 和缓存完成部署，第二次运行也通过，课程档案哈希未变。Python 为 3.12.14。未实测全新机器安装 uv 或真实 Agent 自动发现。Windows PowerShell 5.1 被本机执行策略阻止；没有修改策略，Skill 已说明手动命令路径。内核运行警告保留可见，未导致执行失败。
