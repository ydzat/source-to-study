# 设计记录

简体中文 · [English](README.md)

按主题使用简短编号文件名，放在 `proposed/`、`implemented/` 或 `rejected/`；移动时中英文件一起移动。

提案包含：问题、提案、考虑过的替代方案、验收条件、风险。已实现记录包含：问题、决定、考虑过的替代方案、影响、验证。否决的提案保留理由并注明否决原因。不编造备选方案或验证结果。

同一决定的细节变化更新原记录；不同决定新建记录并互相链接。当前使用规则应保留在各自负责的文件中，不能仅存在于历史记录。

该轻量生命周期参考了 deepseek-harness 的 Agent Note 组织方式，不引入其插件架构、工具链或文档自动化。
