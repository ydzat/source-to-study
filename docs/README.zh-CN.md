# 维护 Source to Study

简体中文 · [English](README.md)

这里面向模板维护者。学习者从[根目录 README](../README.zh-CN.md)开始。

- [架构](architecture.zh-CN.md)：当前文件与职责。
- [约定](conventions.zh-CN.md)：发布边界与双语维护。
- [设计记录](specs/README.zh-CN.md)：提案、决定与验证。
- [教学流程经验](specs/implemented/0007-source-bounded-teaching.zh-CN.md)：为何将课程范围、完整答案和语义检查写成明确执行要求。
- [工作规则审计](specs/implemented/0008-working-rules-audit.zh-CN.md)：表达、疑问句授权、安全编辑与 Markdown 一致性。

非局部改动先在 `specs/proposed/` 记录问题、预期行为、备选方案、验收条件和风险，再按可观察的条件实现。验证完成后移至 `specs/implemented/`，改写为当前决定、影响与验证证据；部分实现不能标成已实现。

使用方法留在学习者文档，开发理由放在这里。每项事实由一份文档负责，其他位置链接引用。错别字或局部措辞修改不必新建提案。
