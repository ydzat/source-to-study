# 架构与首个里程碑

## 设计决定

第一版是**优先在本地运行的流程模板**，不是托管网站。CLI 负责可重复的索引、构建和检查；教学 Notebook 提供交互学习界面。AI 助手可按 `AGENTS.md` 阅读本地来源并起草内容，但不强制使用某个模型或付费服务。

核心能力应实现为普通 Python 函数，未来的浏览器 UI 才能直接调用，而不必复制业务规则。在完全原创的样例能够端到端运行之前，不先开发独立 UI。

## 计划组件

| 层 | 输入 | 输出 | 验证 |
|---|---|---|---|
| 来源导入 | `materials/` 中由使用者持有的文件 | `cache/` 中的本地页码/章节索引 | 文件存在；页数与引用经过核对 |
| 教学 | 来源索引和声明式单元规格 | `output/` 中的 Notebook | 源材料范围完整；干净内核执行；本地资产链接存在 |
| 复习 | 学习者确认的复习真源 | 问题与卡片数据 | schema、引用、空卡与重复卡检查 |
| 导出 | 已验证的卡片数据 | 可选 Anki 包 | 导入前检查包内容和数量 |
| 进度 | 实际教学与学习者作答 | `private/` 中的本地学习日志 | 不因 AI 生成内容而升级掌握状态 |

`examples/` 将放一门完全原创的小课程及预期输出。不能复制大学课件、标识、考试题或私人笔记。样例也是验收测试：新使用者应能从全新检出的目录按说明跑通。

## UI 决定

第一阶段的 UI 就是 Notebook。若以后发现 CLI 明显妨碍新用户，再评估可选的轻量设置/状态界面；核心不依赖它。**ComfyUI 不作为基础依赖**：它的[官方项目说明](https://github.com/Comfy-Org/ComfyUI)以可视化生成媒体工作流为中心，而本项目的主任务是来源索引、引证核验、文字与 Notebook 编写、卡片导出。[JupyterLab](https://docs.jupyter.org/en/stable/start/)已经提供交互式 Notebook 界面。以后若增加可选的图片生成步骤，可以作为边缘集成，不改变核心管线。

## 里程碑

1. 可安全准备公开的双语骨架与明确的公私边界（**当前里程碑**）。
2. 原创小课程、可移植的来源索引和一个 Notebook 构建/检查流程。
3. 复习/卡片 schema、Anki 导出和全新检出环境测试。
4. 基于实际使用评估可选 UI；正式发布前完成内容审计。所有者已为仓库选定 MIT 许可证。
