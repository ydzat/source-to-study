# 维护约定

简体中文 · [English](conventions.md)

## 发布边界

公开内容包括可复用指令、空表单、权利清晰的原创样例和维护文档。个人课件、提取文本、截图、笔记、作答、日志、凭据和衍生资产默认私有。

`materials/`、`study/`、`private/`、`cache/`、`work/` 和 `output/` 均被忽略。发布前检查实际暂存文件及相关 Git 历史，另外检查 Notebook 内嵌输出和二进制资产。忽略规则不会移除已跟踪内容，也不能证明发布权利。保留已有 MIT 许可证；独立授权资产另行注明。

## 语言

说明文档采用 `name.md` 与 `name.zh-CN.md`，同次修改同步。英文是编辑真源，但中文必须能独立使用。路径、标识符和命令保持不变。

`templates/` 的短表单在一个文件中提供双语字段说明。学习者填写的内容使用自己的学习语言，不要求平行翻译，避免同一课程状态出现两份真源。

`.agents/skills/` 每项任务只维护一个英文 `SKILL.md` 指令入口；双语 [Skills 指南](../guides/skills.zh-CN.md)负责向学习者解释，不为翻译另建重复机器入口。共享格式与脚本以链接引用，不复制进 Skill。

## 验证

检查相对链接、语言配对、初始化路径，以及声明的能力与实际文件是否一致。以学习者身份走读表单；文档检查不能证明教学质量。引入可执行能力时，增加行为测试并在干净工作区运行原创样例。

不得把私人父项目的课程内容或机器专属配置复制到公开模板。新增依赖和外部服务需要实际用途及相应授权。
