# 内容、隐私与语言约定

## 公开与私有

| 位置 | 用途 | 是否公开？ |
|---|---|---|
| `examples/` | 完全原创、权利清晰的小课程 | 审查后可以 |
| `docs/`、`AGENTS.md`、可复用代码与测试 | 通用流程 | 审查后可以 |
| `materials/` | 使用者自己的 PDF、课件、图片与数据集 | 默认绝不公开 |
| `private/` | 个人目标、回答、进度和学校规则 | 默认绝不公开 |
| `cache/`、`work/`、`output/` | 提取文本、页图、生成的 Notebook 与卡片 | 默认绝不公开 |

不上传 PDF 还不够：Notebook 可能嵌入课件截图或大段提取文本，[Git 历史也可能保留已经删除的文件](https://docs.github.com/en/repositories/working-with-files/managing-files/deleting-files-in-a-repository)。发布前应逐项审查已跟踪文件、Notebook 输出、二进制文件、内嵌图片、路径和提交历史。公开样例须独立创作；第三方素材及其授权须单独记录，不能认为仓库的总许可证自动覆盖它们。[Creative Commons 也提醒只能授权自己有权授权的内容](https://creativecommons.org/faq/)。

## 双语文档

- 面向使用者的入口和指南有英文、简体中文对应文件：`README.md` ↔ `README.zh-CN.md`，`name.md` ↔ `name.zh-CN.md`。
- 英文是编辑真源，两种语言必须在同一次修改中同步更新；中文版应是完整可用的指南，不是简短摘要。
- 代码、文件名、配置键、命令和标准数学记号保持英文。学习者自己的教学笔记可以用其偏好的语言。
- 测试可以检查必需的文档配对是否存在，但不能证明译文质量，仍需人工核对。

## 证据与学习状态

- 课程事实标注源文件和经过核验的页码/章节；明确区分当前课程证据、跨课程回顾、推导和直觉。
- 教学 Notebook 中，先解释符号再写公式；图紧跟对应讲解；运行代码核对数值例子。
- “已经讲过”“借助提示能够理解”和“独立闭卷复现”是三种不同状态；最后一种只能由学习者的实际回答证明。
- AI 生成的材料在来源核验和学习者审阅前只是草稿；遵守对应课程的学术诚信规则。

## 发布门槛（计划中，尚未自动化）

1. 从全新检出的目录运行测试与原创样例。
2. 确认每个被 Git 跟踪的文件都在允许清单中；单独扫描二进制、Notebook 输出、生成资产和历史。
3. 确认没有私人路径、凭据、受版权保护的课程摘录或未经授权的第三方素材。
4. 确认 MIT 许可证只覆盖所有者有权授权的内容，并记录素材的独立许可。
5. 然后才连接并公开 GitHub 仓库。
