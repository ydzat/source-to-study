## First-session scope

Use **PDF pages 2–13**, a 12-page sequence of three complete sections. These are printed pages 124–135; citations should use the PDF page numbers below.

| Unit | PDF pages | Learning goal |
|---|---|---|
| K01: What is Central Tendency? | 2–8 | Understand why a dataset needs a summary and compare definitions of its center. |
| K02: Measures of Central Tendency | 9–11 | Calculate mean, median, and mode, with each symbol defined. |
| K03: Median and Mean | 12–13 | Connect absolute/squared deviations and the balance point to the appropriate summary. |

Prerequisites: ordering numbers, addition, division, absolute values, and squares. Briefly introduce datasets/distributions, the stem-and-leaf display on PDF p.4, and the median/percentile interpretation when needed. Do not assume prior statistics, calculus, or Python programming. Python code can be supplied and explained by the Agent.

Suggested onboarding budget: **45–60 minutes**, a design estimate rather than an observed completion time. For a shorter session, complete K01 and resume later. Do not teach the remaining chapter merely because it is bundled.

## Why this source fits

The scope offers prose, formulas, tables, figures, and a small worked dataset. Use the source's five values `2, 3, 4, 9, 16` throughout the later notebook: calculate by hand, plot the points and candidate centers, compare deviations, then change one extreme value. Label these new calculations/plots as STS explanations of the source, not original textbook figures or new experimental data.

The learning task stays small while demonstrating source-grounded teaching, visual explanation, executable checks, follow-up revisions, retrieval practice, and optional card generation. The PDF is English; the Agent can teach and create notes in the learner's chosen language.

## Preparation notes for the walkthrough

- Preserve this original PDF. Any future 12-page extract must be a separate file with explicit original-to-extract page mapping and attribution.
- The current Notebook builder requires every page of its input PDF to be assigned exactly once. Do not label excluded pages as recap or weaken that validation. Prepare a documented extract before building the scoped tutorial, or explicitly keep outside-scope units untaught.
- Rendered pages 2–13 were visually inspected with Poppler. Formula text extraction is imperfect; read the page images for the mean formulas on PDF pp.9–10.
- Clarify tied ranks when teaching the median: the source's phrase “same number ... above ... below” must not be read as a strict-count claim for repeated values. Treat the grouped-data mode on PDF p.11 as the source's bin-midpoint convention, not an exact mode for arbitrary continuous data.
- Setup and sample generation do not establish learner mastery. Do not prefill a learning record.
