# Study session / 学习会话

Use one dated record per actual session in `study/sessions/`. / 每次实际学习在该目录保存一份日期化记录。

- Date / 日期:
- Goal and source sections covered / 目标与已讲来源范围:
- Notes and review links / 笔记与复习链接:
- Learner response or task / 学习者作答或任务:
- Assistance provided / 提供了哪些提示:
- Observed outcome / 实际表现:
- Material readiness (separate from learner progress) / 材料就绪程度（与学习进度分开）:
- Learner-reported reading/review completion / 学习者自述阅读或复习完成范围:
- Intentionally skipped scope and reason, if given / 主动跳过的范围及已提供的原因:
- Status: covered, assisted practice, or independently demonstrated / 状态：已讲、辅助练习或独立展示:
- Mistakes and unresolved questions / 错误与待解决问题:
- Next starting point / 下次起点:

Do not infer mastery from generated notes. Record “not tested” when there was no independent check. / 不因生成笔记推断掌握；未经独立检查则记录“未测”。

Preserve unresolved questions when recording completion or a skip. Maintenance alone creates no study session. / 记录完成或跳过时保留待解决问题；单纯维护不创建学习会话。
