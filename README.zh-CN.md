# Source to Study

**把你有权使用的课程材料，转化为有来源依据的笔记、可运行的学习实验、复习问题和间隔复习卡片。**

简体中文 · [English](README.md)

> **项目状态：设计骨架。** 当前尚无可端到端运行的管线或完整样例；下文描述的是目标流程，不表示相应脚本已经实现。

Source to Study 是一套不限定学科和 AI 服务商的辅助复习流程。学习者仍是判断者：AI 可以讲解和起草，来源引证、可执行检查与闭卷复述让结果可以核验。口试是适用场景之一，不是所有课程的默认设定。

## 目标学习闭环

1. 将自己合法获得的材料放入本地、被 Git 忽略的 `materials/` 目录。
2. 建立来源索引；写下课程事实前核对页码或章节。
3. 围绕源材料的学习目标制作教学 Notebook：**目标 → 输入 → 中间对象与操作 → 推导或计算 → 可验证的结果**。
4. 按 **Predict → Run → Break it → Reproduce** 学习；图和例子紧跟其解释的知识点。
5. 维护精炼的复习真源并从中生成卡片；分别记录“已经讲过”和“学习者能够闭卷复现”。

这是**待实现的目标流程**，不是当前骨架已经具备的功能。

## 公开与私有内容边界

公开仓库只收录可复用规则、可移植代码、测试和一门**完全原创**的小课程样例。不会收录作者的大学课件、课件截图、PDF 提取文本、私人笔记、个人学习日志、凭据或由这些材料生成的产物。`.gitignore` 只是第一道保护，不能代替发布前对文件和历史的审查。详见[内容与隐私约定](docs/conventions.zh-CN.md)。

## 计划架构

核心流程将优先在本地运行，且不绑定某一家 AI 服务。Jupyter Notebook 是第一阶段的交互学习界面；只有底层流程可运行、可测试之后才考虑独立 UI。详见[架构](docs/architecture.zh-CN.md)。

## 当前仓库内容

- `AGENTS.md`：供使用者自己的 AI 助手遵循的通用规则，另有中文阅读对照。
- `docs/`：中英成对的设计与安全文档。
- `examples/`：留给未来完全原创、权利清晰的端到端样例。

**目前没有安装步骤。**下一里程碑是一门原创小课程，以及能从全新检出目录对它运行的最小管线。
