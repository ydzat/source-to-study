# Source to Study

简体中文 · [English](README.md)

一套结合 AI 导师复习自己课程材料的通用工作区。从来源出发，形成可核验的讲解，通过不看答案的练习，记录自己能够独立复现的内容。

## 开始你的课程

1. 下载或克隆模板，将你有权使用的课程材料放入本地 `materials/` 目录。
2. 使用能读取本地文件的 AI 助手打开工作区，让它阅读 [AGENTS.md](AGENTS.md)；如果工具不会自动加载该文件，请主动提供。
3. 填写方括号，发送以下提示：

> 阅读 AGENTS.md。根据 templates/course.md，在 study/COURSE.md 中帮我建立课程档案。我的科目是【科目】，学习或考核目标是【目标】，教学语言是【语言】，材料位于【路径】。先询问缺失的学习要求、检查材料并建立来源索引。我们确认范围和起点后再开始教学。

4. 确认起点后，告诉助手：“开始第一个单元，按照 templates/lesson.md 维护笔记。留出提问空间，得到我的确认后再推进。”
5. 实际学习结束后，让助手按照[会话模板](templates/session.md)记录下一步和你的真实表现。新开聊天时，让它先读取课程档案和最新会话，再继续学习。

助手会创建本地 `study/` 目录，保存课程档案、来源索引、笔记、复习问题和会话记录。这些是你的学习文件，不是向公开模板提交的内容。

## 一次学习会留下什么

一份笔记围绕源材料的目标，串起定义、中间步骤、具体例子和可核验结果。插图紧跟对应讲解。你的问题用来发现知识链中的缺口，笔记不会写成聊天流水账。

用[复习问题](templates/review.md)练习回忆，把“读懂”与“能够独立回答”分开。告诉导师你准备的是笔试、口试、项目还是自主学习；模板不预设考核形式。

Markdown 模板无需构建系统即可使用。仓库目前不提供来源提取脚本、Notebook 构建器或 Anki 导出。导师不得编造命令，也不能声称这些能力已经存在。

## 你会用到的文件

- [课程档案](templates/course.md)：目标、来源、语言、考核规则和范围。
- [教学笔记](templates/lesson.md)：有来源依据的完整讲解。
- [复习问题](templates/review.md)：回忆问题与分离的答案。
- [会话记录](templates/session.md)：实际表现与下次起点。
- [原创小样例](examples/README.zh-CN.md)：展示一个学习单元的组织方式。

表单提供中英字段说明；实际学习内容用你选择的语言填写一份即可。

## 保持材料私有

`materials/`、`study/`、`private/`、`cache/`、`work/` 和 `output/` 已被 Git 忽略。忽略规则不是访问控制：把材料交给 AI 前应检查服务商的数据处理方式；公开工作区前应检查已跟踪文件和历史。

[MIT 许可证](LICENSE)适用于模板，不会自动覆盖你的课程材料。只使用你有权使用的材料，并遵守学校的 AI 使用规则。

如果你要维护模板本身，请阅读[开发文档](docs/README.zh-CN.md)。
